# Changelog

## 0.6.0 (2026-11-13)

### Features

- a code editor widget in a new crate, wgpu-gameui-code
- every character on the monospace grid
- word deletes, page scrolling and a sideways width that shrinks
- diagnostics and completion in the code editor
- language-server completion: numbered asks, host edits, resolve

### Documentation

- usage docs on the types users see, and a doc check in the gate
