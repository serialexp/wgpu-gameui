Forge — dark chrome

Section reference

Each file below is one section of the application chrome, rendered as plain static HTML with every state laid out side by side. No framework, no JavaScript, no CSS classes — all values are inline and literal. Start with README.md for the written spec and tokens.md for the value table.

Menu bar The 26px bar: brand mark, titles in idle / hover / open, document tag and dirty dot. Menu sheet Dropdown sheet, the four-column row grid, every item variant, and submenu placement. Toolbar Press keys in all four states, the strip docked to two edges, tooltip and dock popover. Dock panel Edge panels with tab headers and list bodies; splitter idle, hover and drag. Context menu Right-click menu over the viewport, with clamping rules. Status bar Dock toggles, action echo, and the right-hand state readout.
