Context menu

The dropdown sheet, repositioned to the cursor. No separate style, no separate row rules.

Viewport context menu
Identical sheet and row rules as a dropdown — there is no separate context-menu style. It opens at the cursor and is clamped so it cannot overflow the viewport: x capped at width − 236, y at height − 270. Escape, a root click, or activating an item all close it.
