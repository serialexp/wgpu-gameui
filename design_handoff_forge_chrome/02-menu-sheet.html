Menu sheet

One sheet style serves dropdowns, submenus, the context menu and the dock popover. Rows are a fixed four-column grid so labels and shortcuts align regardless of which columns a given row uses.

Full sheet
The File menu, showing the four-column row grid: tick · label · shortcut · submenu arrow. Column positions are fixed whether or not a row uses them, so labels and shortcuts align down the whole sheet.

Submenu
